# Make Something Wonderful Companion

> Read the words. Hear the moment.

[View the live site](https://make-something-wonderful.zmil4.chatgpt.site/)

I made this as an independent reading companion to the [Steve Jobs Archive](https://stevejobsarchive.com/) book [*Make Something Wonderful*](https://book.stevejobsarchive.com/).

The book turns speeches, interviews, and conversations into a reading experience. This site puts some of the original context back around those words: the voice, pacing, audience, and room. It pairs 17 speech-derived passages with the closest public recording or source I could verify.

The intention is not to reproduce the book. It is to make it easier to move between the edited text and the moment it came from.

## How it works

For each passage, the site shows:

- **In the book:** the section, a short quotation, and editorial context.
- **In the room:** the event, date, venue, recording availability, and a link to the source.
- **The relationship:** whether the text is near-verbatim, an edited excerpt, a reused passage, or only partially preserved.

The comparison was built through a systematic section-by-section audit of the official web edition and EPUB. Because the EPUB is reflowable, it has no stable page numbers. Matches were made using section titles, dates, venues, introductory notes, distinctive wording, and the book’s source credits.

## Navigation

- Select a passage from the numbered timeline.
- Use `↑` and `↓` to move between passages.
- Use `Home` and `End` to jump to the first or last passage.
- On smaller screens, use the previous and next controls above the comparison.
- Each passage has a direct URL hash, such as `#macworld-1998`.
- Use **Read in the official book** or **Open source** to visit the linked material.

## Sources and limits

This is a speech-focused companion, not a review of every email, written interview, or artifact in the book.

“Text only” means that I did not locate a reliable public recording during the research. It does not prove that no recording exists. Some surviving recordings are excerpts, edited compilations, or third-party archival copies. Links may move or disappear.

A full recording may also contain material omitted from the published text. Publicly accessible sources are not necessarily in the public domain.

This repository contains the interface, source map, and brief quoted passages. It does not contain the full book or recording files. If you find a stronger source or a broken link, please open an issue with the event details and supporting evidence.
